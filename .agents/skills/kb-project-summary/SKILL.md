# Skill: kb-project-summary

## Purpose
Update the Project's human-readable current-state summary from canonical objects.

## Inputs
Project, active/recent Tasks, latest Checkpoint, unresolved Issues, accepted Decisions.

## Procedure
1. Keep `## Current state` short and current.
2. Mention verified outcomes, active focus, blockers, and next milestone.
3. Link details rather than duplicating long content.
4. Do not change Task statuses here.
5. Update after a material milestone or focus change, not every minor edit.

## Output
A 1-4 paragraph current-state section that remains useful to a human opening the Project first.
