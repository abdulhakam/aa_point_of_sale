# Plan to Replace TanStack Hotkeys with Mantine useHotkeys

## Overview
Replace the usage of `useHotkey` from `@tanstack/react-hotkeys` with Mantine's `useHotkeys` hook in the sections management page. This involves updating imports, consolidating multiple hotkey registrations into a single array-based hook call, and adjusting hotkey string formats to match Mantine's conventions.

## Current State
- Imports `RegisterableHotkey` and `useHotkey` from `@tanstack/react-hotkeys`
- Uses 5 separate `useHotkey` calls for different keyboard shortcuts
- Hotkey strings use lowercase (e.g., "shift+a", "arrowup")
- Some hotkeys have `{ preventDefault: true }` options

## Target State
- Import `useHotkeys` from `@mantine/hooks`
- Use single `useHotkeys` call with array of hotkey tuples
- Update hotkey strings to Mantine format (e.g., "shift+A", "ArrowUp")
- Preserve all existing functionality and options

## Steps

1. **Update Imports**
   - Remove: `import { RegisterableHotkey, useHotkey } from "@tanstack/react-hotkeys";`
   - Add: `import { useHotkeys } from "@mantine/hooks";`

2. **Remove Old Hotkey Registrations**
   - Delete all 5 `useHotkey` calls (lines ~36-65)

3. **Add New useHotkeys Call**
   - Insert after the `useQuery` for sections (after line ~81)
   - Use array format: `[ [hotkey, handler, options?], ... ]`
   - Map existing hotkeys:
     - "shift+a" → "shift+A"
     - "e" → "E" 
     - "delete" → "Delete"
     - "arrowup" → "ArrowUp"
     - "arrowdown" → "ArrowDown"

4. **Verify Functionality**
   - Ensure all hotkey behaviors work identically
   - Check that preventDefault works as expected
   - Confirm conditional logic in handlers (checking selectedIndex and sections) still works

## Assumptions
- `@mantine/hooks` package is available (commonly installed with `@mantine/core`)
- Hotkey strings follow Mantine's case-sensitive format
- Arrow keys use "ArrowUp"/"ArrowDown" (standard KeyboardEvent.key values)
- Delete key uses "Delete"

## Dependencies
- Requires `@mantine/hooks` package to be installed if not already present

## Testing
- Test each hotkey: Shift+A (create), E (edit), Delete (delete), ArrowUp/Down (navigation)
- Verify preventDefault prevents default browser behavior
- Check that hotkeys work when focus is not in input elements
