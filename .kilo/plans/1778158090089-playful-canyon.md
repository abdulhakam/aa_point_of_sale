## Plan to Replace Hotkey Hooks from TanStack to Mantine Core

### Overview
The management pages in `frontend-tb/src/routes/app/management/` currently use hotkey functionality from different libraries:
- Most pages (areas, categories, companies, order_bookers, parties, products) use `useHotkey` from `@tanstack/react-hotkeys`
- The sections page uses `useHotkeys` from `@mantine/hooks`

The task is to replace all uses with `useHotkeys` from `@mantine/core` for consistency.

### Analysis
- **TanStack API**: Uses multiple `useHotkey(key, handler, options)` calls with lowercase keys like "shift+a"
- **Mantine API**: Uses single `useHotkeys([[key, handler, options], ...])` with title-case keys like "shift+A"
- **Sections**: Already uses Mantine API, just needs import change

### Changes Required

#### Files Using TanStack (@tanstack/react-hotkeys):
- `frontend-tb/src/routes/app/management/areas/index.tsx`
- `frontend-tb/src/routes/app/management/categories/index.tsx`
- `frontend-tb/src/routes/app/management/companies/index.tsx`
- `frontend-tb/src/routes/app/management/order_bookers/index.tsx`
- `frontend-tb/src/routes/app/management/parties/index.tsx`
- `frontend-tb/src/routes/app/management/products/index.tsx`

For each:
1. Change import: `import { RegisterableHotkey, useHotkey } from "@tanstack/react-hotkeys";` → `import { useHotkeys } from "@mantine/core";`
2. Replace multiple useHotkey calls with single useHotkeys array
3. Update key casing: "shift+a" → "shift+A", "e" → "E", "delete" → "Delete", "arrowup" → "ArrowUp", "arrowdown" → "ArrowDown"
4. Remove `as RegisterableHotkey` assertions

#### Files Using Mantine Hooks (@mantine/hooks):
- `frontend-tb/src/routes/app/management/sections/index.tsx`

Change import: `import { useHotkeys } from "@mantine/hooks";` → `import { useHotkeys } from "@mantine/core";`

### Assumptions
- `@mantine/core` exports `useHotkeys` (confirmed via docs - it should be available)
- The hotkey behavior remains identical after changes
- No other dependencies on TanStack hotkeys

### Implementation Steps
1. Update imports in all 7 files
2. Refactor hotkey usage in the 6 TanStack files to use array format
3. Test hotkeys functionality in each page
4. Run linting to ensure no errors

### Potential Issues
- If `@mantine/core` doesn't export `useHotkeys`, fall back to `@mantine/hooks`
- Key casing differences might affect functionality - verify hotkeys work correctly
