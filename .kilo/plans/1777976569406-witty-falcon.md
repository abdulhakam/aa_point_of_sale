# Plan: Create Management Page and Add Route

## Goal
Create a management page at `src/routes/app/management/` that serves as a hub to route to the various items management pages (areas, categories, companies, order-bookers, parties, products, sections), and add a "Management" link to the root layout navigation in `src/routes/__root.tsx`.

## Current State Analysis
- The root layout (`src/routes/__root.tsx`) has navigation links for "Home" (/) and "About" (/about).
- The management directory (`src/routes/app/management/`) contains subdirectories for each management item: areas/, categories/, companies/, order-bookers/, parties/, products/, sections/.
- The `areas` subdirectory has files including `index.tsx`, indicating it has a functional route.
- Other subdirectories appear empty, but we assume they will have routes as per the user's request.

## Implementation Steps
1. **Create Management Index Page**
   - Create `src/routes/app/management/index.tsx`
   - This component will render a grid of cards, each representing a management item
   - Display cards for the following entities that have functional routes (presence of `index.tsx`): areas, companies, parties, sections
   - Each card should include:
     - A Tabler icon: IconMap for areas, IconBuilding for companies, IconUsers for parties, IconList for sections
     - The management item name as a link using TanStack Router's `Link` component (e.g., `/app/management/areas`)
     - The total count of items for that entity (fetched using TanStack React DB)
   - Use CSS Grid for the card layout (responsive grid)
   - Fetch counts using separate `useLiveQuery` calls for each collection to get all records, then use data.length for the count (since .count() method is not available in TanStack React DB)
   - Use data?.length to get the count from the fetched records
   - Handle loading states for each query
   - Use Mantine Card components for consistent styling

2. **Update Root Layout Navigation**
   - Modify `src/routes/__root.tsx` to add a "Management" link
   - Add `<Link to='/app/management' className='[&.active]:font-bold'>Management</Link>` to the navigation div
   - Ensure the link styling matches existing links

## Assumptions
- Tabler icons are available in the project (via @tabler/icons-react)
- TanStack React DB collections exist for each entity: areasCollection, companiesCollection, partiesCollection, sectionsCollection
- The app uses TanStack Router for routing, with file-based route definitions
- Mantine UI components are available for card styling
- Cards will be shown only for entities with existing routes and collections

## Validation
- After implementation, verify that navigating to `/app/management` shows the management page with a grid of cards
- Only cards for subdirectories with `index.tsx` should be displayed
- Each card should show an appropriate Tabler icon, the entity name, and the total count
- Clicking on cards should navigate to the respective management item pages
- The "Management" link in the root navigation should be active when on management-related pages
