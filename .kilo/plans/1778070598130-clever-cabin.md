# Plan: Create Management Pages for Order Bookers, Categories, and Products

## Overview
Create management pages (list, create, update) for Order Bookers, Categories, and Products in the frontend-tb application. Implement the companies2orderbookers many-to-many relationship collection similar to companies2parties. Update the main management index to include the new entities.

## Analysis
- **Schemas**: 
  - order_bookers: id (uuid), name, phone, created, updated
  - categories: id (uuid), name, created, updated  
  - products: id (uuid), category (ref), company (ref), cost_price, name, sale_price, box_size_qty, created, updated
  - companies2orderbookers: id (uuid), order_booker (ref), company (ref)
- **Existing Patterns**: Follow companies/parties management structure with CRUD operations, search, hotkeys, modals
- **Relationships**: 
  - Order Bookers ↔ Companies (many-to-many via companies2orderbookers)
  - Products → Categories (many-to-one)
  - Products → Companies (many-to-one)
- **Collections Needed**: order_bookers, categories, products, companies2orderbookers

## Steps

### 1. Create Collections
- **order_bookers.ts**: Similar to companies.ts
  - Type: id string, name string, phone string, created Date, updated Date
  - Parse/serialize timestamps
- **categories.ts**: Similar to companies.ts
  - Type: id string, name string, created Date, updated Date
- **products.ts**: Similar to companies.ts
  - Type: id string, category string, company string, cost_price number, name string, sale_price number, box_size_qty number, created Date, updated Date
  - Parse/serialize timestamps
- **companies2orderbookers.ts**: Similar to companies2parties.ts
  - Fix id type to string (currently number, should match schema BLOB/uuid)
  - Type: id string, order_booker string, company string

### 2. Create Management Routes for Order Bookers
- **order_bookers/index.tsx**: List page with table, search, CRUD modals
  - Join with companies2orderbookers and companies to show associated companies
  - Similar to companies/index.tsx but showing companies instead of parties
- **order_bookers/-CreateOrderBooker.tsx**: Create form
  - Fields: name (required), phone (optional)
  - MultiSelect for companies (similar to companies create selecting parties)
- **order_bookers/-UpdateOrderBooker.tsx**: Update form (similar to update company)

### 3. Create Management Routes for Categories
- **categories/index.tsx**: Simple list page with table, search, CRUD modals
  - Fields: id, name, created, updated, actions
- **categories/-CreateCategory.tsx**: Create form with name field
- **categories/-UpdateCategory.tsx**: Update form

### 4. Create Management Routes for Products
- **products/index.tsx**: List page with table, search, CRUD modals
  - Join with categories and companies to show category name and company name
  - Fields: id, name, category name, company name, cost_price, sale_price, box_size_qty, created, updated, actions
- **products/-CreateProduct.tsx**: Create form
  - Fields: name (required), category (select), company (select), cost_price (optional, default 0), sale_price (optional, default 0), box_size_qty (optional, default 0)
  - Use Select components for category/company from collections
- **products/-UpdateProduct.tsx**: Update form

### 5. Update Main Management Index
- Add Order Bookers, Categories, Products to entities array
- Add corresponding live queries for counts
- Choose appropriate icons: IconUser for Order Bookers, IconTag for Categories, IconPackage for Products

## Dependencies
- Ensure collections are created before routes
- Update imports in management/index.tsx
- Test CRUD operations and joins work correctly
